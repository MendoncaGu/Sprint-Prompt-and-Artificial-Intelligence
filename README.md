# Problema Abordado
Como fazer uma aplicação que originalmente era residencial virar uma aplicação rentável e Comercial

# Proposta do chatbot
Nosso chatbot tem como objetivo criar uma experiência inteligente, automatizada e intuitiva para usuários de carregadores elétricos GoodWe, reduzindo atritos operacionais e elevando a eficiência do ecossistema de mobilidade elétrica.

# Tecnologias Selecionadas
Utilizamos a linguagem de programação python para fazermos nosso chatbot funcionar, juntamente com o google colab. Foram utilizadas bibliotecas python da OpenAI e o modelo chat-gpt 4o mini como a IA responsável pelo chatbot.

# Justificativa Técnica
A escolha de ter feito esse chatbot para essa situação em específico, da-se pelo fato de oferecer automação no processo de carregamento, pagamento e perguntas frequentes de novos usuários. Além de cortar gastos com funcionários auxiliando no carregamento. Temos um robô que faz isso em todos os lugares.
